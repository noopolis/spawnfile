# Authored training configuration

Own strict dataset training controls and declared judge identity. No inference,
filesystem access, template execution or optimization belongs here. Export through
the cases entry point. Unsupported fields and unresolved models fail before work.
Test schema rejections and identity changes with adjacent tests.

Validate opt-in judge protocols and provider-specific completion/context controls
before provider construction. Evidence IDs cannot request citation repairs. Bound
optimizer proposal novelty/history options without implementing optimization here.

Population search is opt-in through optimizer.variants; require keep and
optimizer.budget.rounds with 1 <= keep <= variants. Validate method=gepa, selection,
patience, verbatim boundaries and proposal rewrite_share/hypothesis_similarity.
Existing named-model routing stays unchanged. A declared proposal cap must cover
keep + variants; the CLI derives omitted caps before execution.

training.validation selects a separate contained relative dataset path and is mutually exclusive with validation_groups.

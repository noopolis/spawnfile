# Completed training exports

Owns operator-only local Markdown/JSON summaries, candidate bundles and baseline
patches. Consume public candidate/experiment contracts; never execute, select or
regrade. Export only after a completed training envelope is persisted under sealed
access. Keep immutable snapshots referenced by the invocation index; latest root
companions are convenience copies. Fail the command on artifact write/readback errors.

Preserve missing scores, unknown request counts, price completeness and declared
versus observed fidelity. Rescores replace final measurements, not native captures
or independent sample counts. Round tables distinguish fresh from prior measurements. Never infer
HTTP/model calls from tool calls or subject turns, invoices from API-equivalent
prices, or historical accuracy from closed execution. Runtime reports own timings.
Include recorded decision receipts through the experiment cost seam, including
older envelopes, without repricing existing entries. Traverse grading.gates as
well as children; semantic gate identities and non-pass verdicts must survive.

Run adjacent summary/diff/export tests and CLI command/replay tests. Mutation checks
must catch sealed export bypass, omitted candidates, missing-score inflation,
held-out reselection, and non-applicable patches. Keep files below 400 lines.
Also mutation-check receipt retention, nested deduplication and semantic gates.

Export every evaluated manifest from native reports, including rejected GEPA
proposals absent from final optimizer provenance. Validate baseline policy and
trial identity. Round rows use original attributed native measurements, with prior
captures separate; tests and later rescores cannot enter past search rows. Legacy
unattributed trials remain explicit. Retain failed-grade decisionAccounting too.

Failure traversal carries the producing measurement ID through children and grader
gates. Original turn/live/decisive failures keep the native trial ID even after a
rescore; final checks/stages and the current outcome use the latest measurement ID.
Mutation-check both original and rescored failure attribution.

Infrastructure retry receipts list original/replacement IDs and causes. Preserve all
failed measurements with unknown scores and cost receipts; exclude replaced failed
attempts from split/round means. Replacements alone supply held-out samples.

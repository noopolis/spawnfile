# Spawnfile training context

Consumes the public spawnfile.training-context.v1 context without importing its
compiler. Host composition passes a typed object; containers read a file receipt.
Both paths apply the same schema and canonical byte validation. Verify pinned source bytes and confined document mappings before use.
Source pins hash raw bytes with the producer's 16 MiB limit; selected prompt
resources have their own strict text validation. Never decode inventory bytes.
The receipt is evaluator metadata, never a substitute native instruction file.

Dry-run may resolve candidates, cases and costs, but never compiles, authenticates
or executes an agent. Native runs require their supported isolated preparation;
do not route a compiled project through a generic standalone subject adapter.
Test mutations, ambiguous mappings, unsupported execution and canonical identity.
Population trial sizing belongs to the shared training budget resolver after
datasets are loaded. Integration optimizer settings must reach the same resolver
in dry-run and execution; test a complete declared search with a fake native host.

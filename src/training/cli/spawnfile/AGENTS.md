# Spawnfile CLI handoff

Consumes the public spawnfile.training-context.v1 receipt without importing its
compiler. Verify pinned source bytes and confined document mappings before use.
Source pins hash raw bytes with the producer's 16 MiB limit; selected prompt
resources have their own strict text validation. Never decode inventory bytes.
The receipt is evaluator metadata, never a substitute native instruction file.

Dry-run may resolve candidates, cases and costs, but never compiles, authenticates
or executes an agent. Native runs require their supported isolated preparation;
do not route a compiled Daimon project through the generic Pi adapter.
Test mutations, ambiguous mappings, unsupported execution and canonical identity.

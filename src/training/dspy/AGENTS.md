# DSPy Bridge

Owns the minimal Python boundary to released DSPy 3.3.1 and GEPA 0.1.4.

- Receive versioned candidate components, case references and evaluation feedback
  from the TypeScript owner. Do not reimplement the native subject's cognition.
- Use explicit subscription-backed inference supplied through Paideia; bind every
  enabled DSPy reflection, proposal and judge route without paid API fallback.
- Pin the released DSPy integration seam and test it; upstream main inspection is
  feasibility evidence, not proof the installed version behaves the same way.
- Preserve locked resources and split restrictions. Do not expose sealed-test
  feedback or credentials to optimization requests.
- Tests belong beside Python source and need a language-appropriate coverage gate.
  First acceptance must show the changed candidate reaches a real native subject.
- `protocol.md` specifies the JSONL host contract. `paideia_dspy/` owns the
  process and tests; the root README contains reproducible installation/checks.
- `requirements.lock` pins the exercised dependency closure. A dependency upgrade
  requires the real optimizer conformance test, not source inspection alone.
- Simulated-host tests run actual DSPy optimization and verify changed multi-file
  bundles reach callbacks. They do not establish real native-agent acceptance.

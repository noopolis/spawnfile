# Experiment cost planning

Owns pure, runtime-neutral API-equivalent token valuation and preflight plans.
No model calls, authentication, subprocesses, runtime construction or deployment.

- Price exact model identities against a dated, sourced rate catalog. Unknown
  prices or usage stay unknown; never substitute another model or report zero.
- Input includes cache reads and writes; reasoning is a subset of output.
  Disclose unknown cache-write duration and context tier as a valuation range.
- Subscription billing and hypothetical API token cost are separate quantities.
- Dry-run token ranges are explicit planning assumptions, never spend guarantees.
  Include held-out comparison, every judge, optimizer and unsupported cost sources.
- Test arithmetic, malformed counts, cache semantics and incomplete coverage.
- Keep returned native turn totals before fallible evaluation/collection. Recover
  persisted usage observations when no total returned, but never sum reports
  without a declared cumulative/delta relationship. Report ids are not call ids.
  Partial capture or no observed work yields an unknown overall total; separately
  retain known observed subtotals and every unsummed usage report.
- Accept only validated execution datasets or explicitly non-executable cost
  projections. Report preparation checks as unverified; never imply readiness.
  Cost projections preserve call counts and split identities without native inputs.

Cost planning shares explicit validation selection and evidence-lineage isolation with execution.

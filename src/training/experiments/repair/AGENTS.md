# Measurement repair forks

Owns explicit evaluator upgrades over immutable development captures. It does not
weaken exact resume, launch native agents, choose providers or deploy anything.

- Require a caller-produced compatibility receipt binding both images, immutable
  source/criteria/native closures and exact parent checkpoint digests. Unknown
  adapters or unproved native compatibility fail before any cognition.
- Parent evidence is read-only. Fork IDs and lineage are explicit; old native IDs,
  captured reports, valid grades, optimizer history and cumulative costs remain.
- Development-only imports reject frozen selection and sealed-test migration.
  Original records/candidates must match protected stored blobs, not reconstructed
  guesses. New checks cannot quietly replace the criteria used for a capture.
- Remeasure only authorized failed inference leaves. Reuse valid results exactly,
  recompute affected gates, and append separate linked measurement records.
- Checkpoint owners implement their own import and identity validation. Never edit
  opaque serialized identities from this module or manually replay an LLM response.
- Test genuine GEPA restart, corruption/phase/identity rejection, failed judge-only
  repair, unchanged parent bytes and cumulative costs. Follow inherited size and
  coverage limits; runtime bugs still belong to their runtime owners.

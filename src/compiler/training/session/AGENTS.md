# Training session compiler seams

- `activation.ts` receives the protected execution JSON, reloads the canonical project/context, verifies the complete dataset byte pins, lowers all roles under the durable evaluator output, and binds real compiler/reset/fresh rewind operations. Resume reuses only an exact execution/context receipt and exact lowered file inventory; the registered integration supplies case authoring and domain state only.
- `activation.test-helper.ts` provides test-only v4 declarations for public consumer integration checks; `activation.mutation.test.ts` removes identity, dataset pin, handoff and authored-edit guards in an isolated tree and requires their labelled assertions to fail.
- `candidate.ts` snapshots the canonical project, checks source pins and locked resources, overlays candidate bytes before real compilation, and persists a compilation receipt. The scratch is evaluator-only and disjoint from source and subject roots.
- `snapshot.ts` retains a self-contained Git identity when declared build resources need it. Credential paths are refused; no credential or realm is copied into a candidate.
- `recycle.ts` speaks only the root supervisor's bounded recycle protocol with cancellation, slot and nonce binding.
- `slot.ts` verifies the leased descriptor, shared broker declaration, fresh generation/nonce and complete native preflight before returning launch projection fields. The supervisor owns reset; Paideia owns scheduling, quarantine and closure.
- Public exports live in `index.ts` and the parent training entry point. Domain state, transport and accepted-output reconstruction belong to the declared private hook.
- Keep adjacent positive/negative tests and isolated mutation checks; use a worktree-local TMPDIR. No model or Docker calls in fake scheduling tests.
- Activation mutations also restore absolute resource scope/pin addresses and
  require the real host-to-container relocation assertions to fail.
- `fixtures.test-helper.ts` is test-only broker/preflight construction shared by slot and protected-metadata tests.

- Activation binds candidate `sourceRoot` to the enclosing declared input carried
  in the protected execution receipt; callers cannot replace it. Mapping and
  resume identity retain it. Nested org bundle builds preserve sibling files
  and self-contained Git identity. Candidate bundle cache defaults to evaluator
  scratch, never the image's read-only home.
- `activation.source-root.test.ts` exercises real nested-repository compilation
  and emitted bundle bytes; activation mutations delete lowering, mapping and
  compiler root binding independently.

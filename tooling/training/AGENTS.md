# Repository tooling

Owns mechanical development gates, never agent execution or evaluation semantics.
TypeScript modules enter the same size, directory, guide and coverage checks as
product code. Export through child public indexes; keep tests beside the rule.

- Test the real ESLint gate with a violating fixture, not only rule helpers.
- No production credentials, provider calls or deployments in CI.
- Run targeted tooling tests while editing; the final gate includes npm run check.
